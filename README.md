# Marion — page « 💪 Séance »

Page statique ouverte depuis le bot Telegram de Marion (coach sportif). Elle ne contient aucune donnée :
la séance du jour arrive dans le fragment de l'adresse (`#z=…`), jamais envoyé au serveur, et le bilan
repart vers le bot par Telegram. Fichiers générés depuis le dépôt privé du bot (`webapp/`) : ne pas modifier ici.
